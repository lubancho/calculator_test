# Калькулятор стоимости сайта

Одностраничное веб-приложение для менеджера digital-агентства: предварительная оценка стоимости и сроков разработки сайта с выгрузкой клиентской сметы в PDF.

## 1. Назначение приложения

Менеджер выбирает параметры будущего сайта и сразу получает предварительную стоимость, ориентировочный срок и прозрачную детализацию — без Excel и без обращения к разработчикам. Результат можно скопировать текстом (Telegram, email, CRM) или скачать оформленную смету в PDF для клиента.

## 2. Функциональные возможности

- Выбор типа сайта (лендинг, корпоративный сайт, интернет-магазин) карточками с radio-переключателями.
- Количество страниц от 1 до 100: кнопки «−»/«+», ручной ввод, стрелки ↑/↓. Промежуточный ввод не блокируется; после завершения ввода (Enter или уход из поля) значение нормализуется: 0 и отрицательные → 1, дробные округляются, больше 100 → 100, пустое/нечисловое → последнее корректное значение. О каждой коррекции выводится сообщение.
- Дополнительные функции (чекбоксы) с ценой и сроком у каждой.
- Срочность: стандартная, ускоренная, срочная.
- Автоматический пересчёт при любом изменении; детализация, формула срока, динамическое пояснение и предупреждение о предварительном характере расчёта.
- «Скопировать расчёт» — текст для мессенджеров/почты/CRM; если браузер запрещает доступ к буферу, показывается поле с уже выделенным текстом.
- «Скачать PDF для клиента» — A4, кириллица и ₽, выделяемый текст, переносы длинных названий, многостраничность с нумерацией «Стр. N из M». Защита от повторного запуска, индикация на кнопке, сообщение об ошибке, резервная ссылка «открыть файл» для мобильных браузеров.
- «Сбросить» — лендинг, 1 страница, без функций, стандартная срочность (35 000 ₽, 7 рабочих дней).
- Адаптивность 320–1440+ px, sticky-блок результатов на широких экранах (если он целиком помещается по высоте), плавающая сводка «итог + срок» на узких экранах.
- Доступность: семантическая разметка, связанные подписи, видимый фокус, полная работа с клавиатуры, `aria-live` для итога и уведомлений, `prefers-reduced-motion`, выбранное состояние показывается не только цветом (точка/галочка, рамка).

## 3. Использованные технологии

- HTML5, CSS3, Vanilla JavaScript (ES5+, без сборки и фреймворков).
- [jsPDF 4.2.1](https://github.com/parallax/jsPDF) и [jsPDF-AutoTable 5.0.9](https://github.com/simonbengtsson/jsPDF-AutoTable) — лицензия MIT, лежат локально в `assets/vendor/`.
- Шрифт [Inter](https://rsms.me/inter/) (SIL OFL 1.1): подмножество woff2 для интерфейса и TTF в base64 (`assets/fonts/pdf-fonts.js`) для PDF.
- Никаких внешних запросов: CDN, аналитика и серверные API не используются.

## 4. Локальный запуск

Достаточно открыть `index.html` двойным щелчком — всё, включая PDF, работает по `file://` без сервера.

Чтобы проверить в условиях, близких к GitHub Pages, запустите любой статический сервер из папки проекта:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Тесты:

```bash
node --test tests/calculator.test.js          # 43 модульных теста, Node.js 18+
# или откройте tests/run-in-browser.html в браузере
pip install playwright && python -m playwright install chromium
python tests/e2e_playwright.py                # 115 сквозных проверок, нужен pdftotext
```

## 5. Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `website-calculator`), публичный или с тарифом, поддерживающим Pages.
2. Загрузите содержимое папки так, чтобы `index.html` лежал **в корне** репозитория:
   ```bash
   git init
   git add .
   git commit -m "Калькулятор стоимости сайта"
   git branch -M main
   git remote add origin https://github.com/<логин>/website-calculator.git
   git push -u origin main
   ```
   Или через веб-интерфейс: *Add file → Upload files*, перетащить все файлы и папки.
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/website-calculator/`.
5. **Проверьте опубликованную версию:** откройте URL, измените параметры, скопируйте расчёт, скачайте PDF и сверьте сумму и срок с экраном. Все пути относительные, поэтому работают и в подпапке репозитория.

Файл `.nojekyll` в корне отключает обработку Jekyll (не обязателен, но исключает сюрпризы с файлами и папками).

## 6. Логика расчёта

Вся логика — в одной функции `calculate(params)` в `script.js`. Интерфейс, копирование и PDF используют только её результат; PDF-генератор ничего не пересчитывает, а перед созданием документа сверяет, что сумма строк равна итогу (`verifyResult`).

```
Доп. страницы       = max(0, Выбрано страниц − Включено в тариф)
Базовая сумма       = Цена типа + Доп. страницы × Цена страницы + Σ Цена функций
Наценка             = round(Базовая сумма × (Коэфф. цены − 1))
Итоговая стоимость  = Базовая сумма + Наценка

Базовая продолжит.  = Срок типа + Доп. страницы × Срок страницы + Σ Срок функций
Итоговый срок       = max(1, ceil(Базовая продолжит. × Коэфф. срока))
```

Сроки — в рабочих днях, работы последовательные, календарная дата не рассчитывается.

Защита от ошибок плавающей точки: в JS `20 × 0,65 = 13,000000000000002`, и наивное `Math.ceil` дало бы 14 дней. Поэтому коэффициенты переводятся в целые базисные пункты, длительность — в сотые доли дня, и округление вверх выполняется целочисленным делением.

## 7. Демонстрационный характер тарифов

Все цены, сроки, коэффициенты и название «Digital Agency» — демонстрационные. Модель не учитывает НДС, скидки, хостинг, домен, сопровождение и ресурсное планирование команды. Расчёт предварительный и не является офертой. «Интеграция с CRM» — оцениваемая услуга по разработке сайта, а не функция самого калькулятора.

## 8. Как изменить цены и сроки

Откройте `script.js` и измените объект `CONFIG` в начале файла — логику трогать не нужно:

```javascript
var CONFIG = {
  agencyName: 'Digital Agency',            // название в PDF
  pages: { min: 1, max: 100 },
  projectTypes: {
    landing: { name: 'Лендинг', price: 35000, duration: 7, includedPages: 1,
               extraPagePrice: 5000, extraPageDuration: 1, ... },
    ...
  },
  features: [
    { id: 'form', name: 'Форма заявки', price: 5000, duration: 1 },
    ...                                    // добавьте объект — появится новый чекбокс
  ],
  urgency: {
    fast: { name: 'Ускоренная', priceFactor: 1.2, durationFactor: 0.8,
            description: '+20% к стоимости, срок меньше на 20%',
            lineItem: 'Ускоренное выполнение' },
    ...
  }
};
```

- Карточки, чекбоксы, подписи, детализация, текст для копирования и PDF строятся из `CONFIG` автоматически.
- При изменении коэффициента срочности обновите и `description` — это текст для людей.
- Для нового типа сайта задайте также `nameLower` и `nameGenitive` (используются в пояснении и в PDF: «Разработка корпоративного сайта»).
- Если в названиях понадобятся символы вне латиницы, кириллицы и основной пунктуации, пересоберите `assets/fonts/pdf-fonts.js` из полного TTF Inter (подмножество выбрано, чтобы файл весил ~75 КБ).
- После изменений запустите `node --test tests/calculator.test.js` и `python tests/make_examples.py` и при необходимости поправьте ожидаемые значения в `tests/test-cases.js`.
